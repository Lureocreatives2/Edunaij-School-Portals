# Security

This project is in development; no release carries a production security assurance commitment.

Do not disclose vulnerabilities, credentials or student information in public issues. Use GitHub private vulnerability reporting through the repository Security tab if enabled. Otherwise ask the maintainer for a private channel without publishing exploit details. A maintainer contact has not yet been configured.

Provide reproduction steps using synthetic data, affected code and impact. Remove credentials and personal information from logs. Coordinate disclosure after remediation.

Maintainers should enable private reporting, review dependency alerts and test tenant boundaries, protected files and payment callbacks before releases.
