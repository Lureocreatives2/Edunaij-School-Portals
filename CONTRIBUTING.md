# Contributing

edunaij is all rights reserved. Get the owner's permission before reusing, modifying or redistributing project code, subject to applicable law and hosting-platform terms. See LICENSE. Follow the README setup, create a focused branch and describe the problem and resulting behaviour in your pull request.

Run `python scripts/check_project.py` in the project environment. Include migrations for model changes. Test school boundaries using multiple tenants and user roles. Check interface changes on narrow screens and with keyboard navigation.

Use synthetic records. Never commit secrets, databases, exports, uploads or real student information. Do not seed automatic administrator accounts. Report security concerns privately using SECURITY.md.
